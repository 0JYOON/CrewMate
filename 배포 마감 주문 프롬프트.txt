지금 수정한 내용으로 지인들에게 새 버전 배포를 준비할 거야. 아래 4가지를 순서대로 진행해 줘.

1. 버전 업데이트: `app/build.gradle.kts`에서 `versionCode`를 1 올리고, `versionName`을 "1.0.1"로 변경해 줘. (버전 숫자는 상황에 맞게 수정)
2. 문서 기록: `AGENTS.md` 수칙에 따라 `CHANGELOG.md`, `DEVELOPMENT_HISTORY.md`, `ARCHITECTURE_GUIDE.md`를 최신화해 줘.
3. Git 저장: 지금까지 변경된 모든 코드와 문서를 한글 요약 메시지와 함께 Git Commit 해 줘.
4. 정식 APK 생성: 기존 `crewmate-release-key.jks` 서명 키로 `assembleRelease`를 실행하고, 완성된 파일을 프로젝트 루트 폴더에 `CrewMate_v1.0.1.apk` 이름으로 복사해 줘. (끝나면 SHA-256 해시값도 함께 알려줘.)
